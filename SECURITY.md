# Security policy

## Reporting a vulnerability

Please report it privately through [GitHub's private vulnerability reporting](https://github.com/farulivan/roomflow/security/advisories/new), not in a public issue. I aim to reply within a week.

## Scope

Roomflow is a demo. Its API is a mock that runs in the browser, and it holds no real accounts or guest data. Reports are welcome about:

- the deployed site at [roomflow.farulivan.com](https://roomflow.farulivan.com)
- the build and its dependencies
- this repository's workflows

Only the latest `main` is supported.
